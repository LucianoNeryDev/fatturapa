# Changelog

## 0.1.0 - Unreleased

First release.

- `renderInvoicePdf(input, options?)` renders the PDF courtesy copy of an invoice built with `@lucianonerydev/fatturapa` 0.2: header, parties, references, lines with discounts, VAT summary, totals with pension funds, withholdings and stamp duty, payment details with instalments, and a footer stating the copy has no fiscal value.
- Hand-written PDF 1.4 writer with the base-14 Helvetica fonts, real Helvetica metrics for wrapping and alignment, and deterministic output.
